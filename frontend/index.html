How to connect your real accounts in 60 seconds:

SwytchCode manages OAuth tokens securely in your local environment. Run these in your terminal:

1. Connect GitHub (OAuth in browser): swy auth connect github
2. Connect Jira: swy auth connect jira
3. Connect Slack: swy auth connect slack
4. Verify connected state: swy auth status

💡 Alternatively, add GITHUB_TOKEN, JIRA_API_TOKEN, and SLACK_BOT_TOKEN to your .env file.
